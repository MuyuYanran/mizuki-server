# @mizuki/web（管理前端，P10 阶段）

本目录为 Mizuki-Server 的管理前端，**当前为最小占位**，将在 **P10** 阶段实现。

## 计划技术栈（P10）

- **Vue 3** + Vite + TypeScript
- **Element Plus** —— UI 组件库
- **TipTap** —— 富文本文章编辑器
- **CodeMirror** —— 代码 / Markdown 编辑
- 统一通过服务端全局前缀 **`/api/v1`** 与 `@mizuki/server` 通信

## 当前状态

P0a 阶段仅保留最小 `package.json`（name `@mizuki/web`，private）。所有前端实现推迟至 P10 提示词。
