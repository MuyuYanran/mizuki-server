## 一、流程规则（Phase3-F 转正四项）

### R1 部署拓扑检查项

- **规则条文**：凡涉及 URL 拼装、绑定地址、cookie domain 的批次，提示词起草与评审
  两处均须列入检查单：hostname / cookie domain / 实际访问形态（localhost 与
  127.0.0.1 双形态、反向代理与公网域名）三者匹配一致性逐项核对；实现一律自
  `window.location.hostname` 或请求 Host 派生，禁硬编码 `127.0.0.1`。
- **缘起批次**：Phase3-C4（T4.1 实证 hostname 硬编码 127.0.0.1 在 localhost 与
  127.0.0.1 双访问形态下破坏 cookie host 匹配，C4 v2 修订为先例实现）。
- **先例链接**：REQUIREMENTS-PHASE3 §1.7 候选行（C4 先例 + C5 处置记录）；C4 SESSIONS。

### R2 前置检查条件化规则

- **规则条文**：批次提示词 §1 前置检查失败时，仅当以下**双条件同时满足**方可记偏差
  继续，任一不满足必须停止报告：①「可证实从未存在」而非「误删」（有撤销/未产出
  的记录可查）；②下游重释无歧义（替代载体/口径可唯一确定，不产生第二种理解）。
- **缘起批次**：Phase3-C5（checklist 载体先例：C6 撤销使原定载体从未产出，C5 以
  「收口产物即载体」方式满足双条件后记偏差继续）。
- **先例链接**：docs/DEPLOYMENT-CHECKLIST.md 载体由来行；REQUIREMENTS-PHASE3 §1.5。

### R3 四格语义表

- **规则条文**：实现级终行（schema 终行 / 管线分派 / 命令形态）交付时一律附
  **四格语义表**：键缺失 / 空串 / 非法 / 合法四格各落一格（语义与处置），锚例同交付。
  分派类规则（如缓存三档分派）不属四格触发范畴，以**分派表**交付。
- **缘起批次**：Phase3-C5（posts lang 终行先例，C7 沿用并正式提出）。
- **先例链接**：CHANGELOG Phase3-C5/C7 节；C5/C7 SESSIONS 四格表交付记录。

### R4 裁决复用域核验

- **规则条文**：跨字段域 / 跨上下文复用先例裁决时，须附**目标域取值实况核验**
  （直接读目标域常量、类型定义或数据验证取值形态），禁凭记忆引用先例口径。
- **缘起批次**：Phase3-C7（zh_CN 先例：复用 C5 lang 裁决前实测主题 `SITE_LANG = "zh_CN"`
  下划线形并记核验记录，由此识别出两域口径差异——F 批 siteLangSchema 拆分即其落地）。
- **先例链接**：docs/SESSIONS.md Phase3-C7 交付报告 §3 实施要点（SITE_LANG 常量代入
  实况核验记录）。
