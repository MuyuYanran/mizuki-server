# 图片语法

这是在 Mizuki 8.0 以上加入的新特性，支持你为图片设置缩放比例、标题和居中对齐！

## 使用方法

使用以下语法可以设置图片的缩放比例、标题和居中对齐：

```md
![图片描述 w-50%](图片链接 "图片标题")
```

其中：

- `w-50%` 表示图片宽度为 50%（可以是任意百分比）
- `"图片标题"` 表示图片的标题（可选）
