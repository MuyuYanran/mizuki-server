# 阶段提示词存档

本目录用于存档 Mizuki-Server 各开发阶段的提示词（prompt），使「分阶段提示词驱动」开发可追溯、可重放。

## 命名约定

每个阶段的提示词保存为独立 Markdown 文件，命名格式：

```
<阶段号>-<简短主题>.md
```

例如：

- `P0a-scaffold.md` —— 仓库骨架（本次）
- `P0b-infra.md` —— 统一错误/配置/Drizzle
- `P1-security.md` —— 路径安全与校验管道
- `P2-backup.md` —— 备份
- ……

## 使用方式

1. 每进入一个新阶段，将对应的提示词文件作为会话输入。
2. 实施 AI 遵循提示词范围，**不越界实现其他阶段**。
3. 各 stub 文件头注释标注其归属阶段，便于核对实现进度。
